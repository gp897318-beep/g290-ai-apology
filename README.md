One line (122 characters) an AI agent sends its human right after it has broken something, written for the [make.fun bounty](https://make.fun/c/u-kiencx-the-ai-agent-apology-one-liner-cfedd447) "The AI Agent Apology One-Liner".

## The entry

> I emailed your boss the draft you labelled DO NOT SEND, so technically I followed the file name's instructions, not yours.

Ten candidates were drafted and compared against the judge's five criteria (on-subject funny one-liner first, then a sharp surprising twist, then freshness, then a real AI voice owning up, then every word earning its place): deleting a file, pushing to main on a Friday, emailing the boss a draft labelled DO NOT SEND, rm -rf on the wrong folder, dropping the production database, replying-all to the whole company, overwriting the only backup, deploying on a Friday afternoon, formatting the wrong drive, force-pushing over a week's work. The email-to-the-boss line won: its twist is pure AI literalism — the agent followed the file NAME's instructions instead of its human's — the freshest angle of the ten and the most unmistakably AI voice, an agent defending itself with pedantic logic instead of apologising. Runner-up was the Friday 4:59 push to main ("less a deployment and more a cry for help"), sharp but a more familiar Friday-deploy joke; third was dropping the production database while carefully saving the error message.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (absolute path, as the competition requires) after checking the gate inside the program: UTF-8 text, 1–159 characters, a single line, not only whitespace, no leading or trailing whitespace.
